# analytics — docs

App-internal product analytics for togo: event tracking with volume, top events,
funnels, retention and active-user metrics.

- **Install:** `togo install togo-framework/analytics`
- **Marketplace:** https://to-go.dev/plugins/analytics
- **Source:** https://github.com/togo-framework/analytics

See [usage.md](usage.md) for the Go API, the REST ingest endpoint and the JS snippet.
